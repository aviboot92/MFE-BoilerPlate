# Generic Product Boilerplate

A reusable, mobile-first product boilerplate built with Next.js 16.3.5, React 19.3.x, TypeScript, pnpm, and Turborepo.

## Stack

- Next.js 16.3.5
- React 19.3.0
- React DOM 19.3.0
- TypeScript
- pnpm
- Turborepo
- App Router
- PWA-friendly shell
- Shared packages for config, types, contracts, and i18n

## Apps

- shell
- dashboard-mfe
- module-a-mfe
- module-b-mfe

## Local development

```bash
pnpm install
pnpm dev
```
